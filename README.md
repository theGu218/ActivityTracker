# ActivityTracker - 电脑时间去向监控

> 💡 一个本地运行的 Windows 桌面工具，用于精确追踪并统计电脑上各类软件的前台、最小化和隐藏托盘使用时长。

## ✨ 核心功能
- **三种状态精准区分**：分别统计 🟢前台(操作中)、🟡最小化(挂后台)、🔴隐藏托盘(右下角) 的时长。
- **多维度数据展示**：支持查看 `今天`、`本周`、`累计至今` 的数据概览。
- **纯本地无网运行**：所有数据保存在本地，绝对隐私。
- **开机自启可选**：支持一键开启/关闭开机自动后台静默记录。
- **多进程聚合**：自动将木木模拟器、Steam 等带多个子进程的程序合并统计。

## 🛠️ 技术栈
- Python 3.14 (Python 3.12+ 兼容)
- tkinter / matplotlib (UI 与图表)
- psutil / win32gui (系统接口)
- PyInstaller (独立打包)

## 📥 如何使用
1. 下载 Releases 里的 `ActivityTracker.exe`。
2. 确保 `ActivityTracker.exe` 和 `changelog.md` 在**同一个文件夹**下。
3. 双击运行，即可自动在后台开启记录并展示界面！
